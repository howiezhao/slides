# Welcome to my slides!

This is a space for archiving the slides I've created and shared.

All the slides can be viewed at https://howiezhao.github.io/slides, or on Slideshare.

## Start

To start the slide show locally:

- `npm install`
- `npm run dev -- <specific slides file>`, such as `npm run dev -- slides-it-troubleshooting`.md
- visit <http://localhost:3030>
